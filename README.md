# Wicked Witch of the Woods (Foundry VTT module)

Table-side content for running *Wicked Witch of the Woods* with the
[Shadowdark RPG system](https://foundryvtt.com/packages/shadowdark) on Foundry VTT 13 or 14.

This repository is generated output. Do not edit it by hand: the module is built from a
private Obsidian vault with `_foundry/release.sh <version>`.

## Install

Paste this manifest URL into Foundry's **Install Module** dialog (on Sqyre: game detail page,
MANAGE GAME, Manage Modules):

```
https://synth-rabbit.github.io/wicked-witch-of-the-woods-module/module.json
```

Enable the module in a Shadowdark world, open the **Wicked Witch of the Woods** compendium and
import the adventure.

## What it contains

- Three scenes: Waldheim, the Witch's Cottage (walls, doors, a secret door) and the Witch's
  Cellar (total darkness), with GM-only numbered room pins.
- The adventure's creatures and villagers, and six pregenerated level 1 characters.
- Its items, potions, herbs and conditions.
- Two random encounter tables, a GM-only room key and two player handouts.
- A witch countdown the GM controls: token controls toolbar (hourglass) or Alt+T.

Updating the module does not update documents already imported into a world. Re-import the
adventure to pick up changes.
